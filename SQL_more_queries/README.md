Bu layihə MySQL üzərində verilənlər bazalarının və 
cədvəllərin sıfırdan yaradılması, silinməsi və
strukturunun idarə olunmasını əhatə edir. Layihə
çərçivəsində cədvəllərə məlumatların daxil edilməsi,
mövcud verilənlərin yenilənməsi (`UPDATE`) və
silinməsi (`DELETE`) tapşırıqları yerinə
yetirilmişdir.
